# 오늘의 명언 — 명언카드

한국어 명언을 카드 형태로 보여 주는 웹 페이지입니다. 새로운 명언을 무작위로 확인하고, 마음에 남은 문장을 직접 추가하거나 공유할 수 있습니다.

이 문서는 2026년 11월 9일 현재 `index.html`, `style.css`, `script.js`에 구현된 내용을 기준으로 작성했습니다.

## 구현된 기능

### 1. 명언 표시 및 무작위 선택

- 기본 한국어 명언 22개를 문장(`text`)과 저자(`author`) 쌍으로 제공합니다.
- 페이지를 열면 명언 하나를 즉시 무작위로 표시합니다.
- **새 명언 생성** 버튼을 누르면 목록에서 다른 명언을 선택합니다.
- 직전에 표시한 명언은 연속으로 나오지 않습니다. 그 이전에 본 명언은 다시 나올 수 있습니다.
- 사용자가 추가한 명언도 무작위 선택 대상에 포함됩니다.
- 버튼의 ‘생성’은 저장된 목록에서 고르는 동작이며, AI나 외부 API로 문장을 생성하는 기능은 없습니다.

### 2. 명언 전환 애니메이션

- 명언 본문과 저자 영역만 페이드 전환하고, 버튼과 입력 폼은 유지합니다.
- 0.35초 동안 사라진 후 내용을 바꾸고, 0.35초 동안 다시 나타납니다.
- 전환 중 버튼을 여러 번 눌러도 추가 요청을 하나로 모아 현재 전환이 끝난 뒤 처리합니다.

### 3. 내 명언 추가

- 명언과 저자를 입력해 저장할 수 있습니다.
- 입력값 앞뒤 공백을 제거하며, 명언이 비어 있거나 공백뿐이면 저장하지 않습니다.
- 저자를 비워 두면 **익명**으로 저장합니다.
- 문장과 저자가 모두 같은 항목이 기본 목록 또는 사용자 목록에 있으면 중복 저장을 막습니다.
- 저장한 명언은 카드에 즉시 표시하고 입력 폼을 초기화합니다.
- 사용자 명언은 브라우저 `localStorage`에 저장해 같은 저장 공간에서 다시 열 때 불러옵니다.
- 저장된 데이터가 JSON으로 해석되지 않거나 배열이 아니면 기본 명언으로 시작합니다. 불러올 때 문장이 없거나 비어 있는 항목은 건너뜁니다.

### 4. 공유 및 복사

- **공유하기** 버튼으로 현재 표시된 명언을 `“명언” — 저자` 형식으로 전달합니다.
- 브라우저가 Web Share API를 지원하면 운영체제의 공유 창을 엽니다.
- 공유 API가 없거나 공유에 실패하면 Clipboard API로 복사를 시도합니다.
- 사용자가 공유 창을 취소한 경우에는 복사를 진행하지 않습니다.
- 공유·복사 결과와 저장 안내 메시지는 약 2.5초 동안 표시합니다.

### 5. 라이트·다크 테마

- 화면 오른쪽 위 버튼으로 라이트와 다크 테마를 선택합니다.
- CSS 사용자 정의 속성으로 배경, 카드, 글자, 입력창, 버튼 색상을 전환합니다.
- 테마 선택을 `localStorage`에 저장하고 다음 방문에 복원합니다. 기본값은 라이트입니다.
- 화면이 그려지기 전에 저장된 테마를 적용해 초기 깜빡임을 줄입니다.
- 선택된 테마 버튼은 색상과 `aria-pressed` 상태로 표시합니다.

### 6. 화면 구성 및 접근성

- 그라데이션 배경, 둥근 카드, 그림자, 알약 형태 버튼을 적용했습니다.
- 카드 너비는 최대 560px이며, 작은 화면에서는 사용 가능한 너비에 맞춥니다.
- 화면 너비 480px 이하에서는 카드 여백과 명언 글자 크기 등을 줄입니다.
- 화면 높이 860px 이상에서는 카드를 세로 중앙에 배치합니다.
- 입력 필드에 레이블을 연결하고 버튼과 입력 요소에 키보드 포커스 표시를 제공합니다.
- 명언 변경과 상태 메시지에 `aria-live="polite"`를 적용했습니다.
- 사용자 입력과 명언은 `textContent`로 출력합니다.

## 기술 구성

| 구분 | 사용 기술 |
| --- | --- |
| 문서 및 화면 구조 | HTML5 |
| 스타일 | CSS3, CSS 사용자 정의 속성, Flexbox, 미디어 쿼리 |
| 동작 | Vanilla JavaScript |
| 데이터 저장 | 브라우저 Local Storage |
| 공유 및 복사 | Web Share API, Clipboard API |

별도 프레임워크, 패키지 설치, 빌드 과정, 백엔드 서버, API 키 없이 구성한 정적 웹 페이지입니다. 폰트는 CSS에 지정된 로컬 폰트를 순서대로 사용하며, 외부 웹폰트를 내려받는 코드는 없습니다.

## 파일 구조

```text
vibe-1108-curos-wisdom/
├── index.html   # 카드, 테마 버튼, 명언 추가 폼 및 초기 테마 적용
├── style.css    # 테마 색상, 카드 스타일, 페이드 효과 및 반응형 레이아웃
├── script.js    # 명언 데이터, 무작위 선택, 저장, 공유 및 이벤트 처리
└── README.md    # 현재 구현 내용과 실행 안내
```

## 실행 방법

1. 프로젝트 폴더의 `index.html`을 브라우저로 엽니다.
2. **새 명언 생성**으로 명언을 바꾸거나, **내 명언 추가** 폼으로 문장을 저장합니다.
3. 오른쪽 위 테마 버튼으로 화면 테마를 바꾸고, **공유하기**로 현재 명언을 공유하거나 복사합니다.

공유와 클립보드 기능은 브라우저 지원 여부, 권한 및 보안 컨텍스트에 따라 달라집니다. 해당 기능을 확인할 때는 HTTPS 또는 `localhost` 환경에서 실행하는 것이 좋습니다. Python이 설치되어 있다면 프로젝트 폴더에서 아래 명령으로 로컬 서버를 열 수 있습니다.

```powershell
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다. 서버는 터미널에서 `Ctrl+C`로 종료합니다.

## 저장 데이터

| 키 | 저장 내용 | 형식 |
| --- | --- | --- |
| `custom-quotes` | 사용자가 추가한 명언 목록 | `{ "text": "문장", "author": "저자" }` 객체의 JSON 배열 |
| `quote-theme` | 선택한 테마 | `light` 또는 `dark` 문자열 |

기본 명언 22개는 `script.js`에 있으며 사용자 저장 데이터와 별도로 관리합니다. 데이터는 해당 브라우저의 사이트 저장 공간에 남으므로 다른 브라우저·기기와 자동으로 동기화되지 않습니다. 접속 주소가 달라지면 저장 공간도 달라질 수 있고, 사이트 데이터를 삭제하면 추가 명언과 테마 설정이 지워집니다.

## 현재 범위

현재 구현은 명언 조회·추가·공유와 테마 전환까지입니다. 사용자 명언 수정·삭제, 즐겨찾기, 카테고리 선택, 검색, 카드 이미지 다운로드, 로그인 및 서버 동기화 기능은 아직 구현되어 있지 않습니다.

기본 명언을 수정하거나 추가하려면 `script.js`의 `quotes` 배열을 편집합니다. 페이드 시간을 변경할 때는 `script.js`의 `FADE_MS`와 `style.css`의 `.quote-body` 전환 시간을 함께 맞춰야 합니다.
